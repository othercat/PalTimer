# SDLPAL r135 计时器与在线配置

本版配套 Pal98Timer 3.38.6.18、PalTimerOnline 1.0.2.14 与对应的认证组件及公开登记。更新现有计时器时先退出程序，整组备份这四件文件，出现问题时整组恢复。既有 PB、时间线和用户配置保留。

完整包 Sources 目录中的 challenge-rules-sdlpal.file.json 供服务器导入。challenge-rules.v2.json 供配置工具和引擎核对。计时器读取本次生效的玩法、优先级以及引擎报告的本局规则摘要。战斗有序关闭时沿用原分类，启用时计入规则及优先级。原版设置、隔世设置对本局产生的效果随游戏报告的摘要区分。

隔世追凶在全剧终第一次显示时停表。其余内容恢复各自的默认终点。旧引擎仍可识别，r132–r134 的晚停表记录保留当时的分类。已经保存过自定义节点的玩家，可在自动节点编辑器选择恢复默认并保存。余杭首富继续使用专属庆祝终点。

游戏计时器的 OBS 独立遮罩默认使用可采集的普通顶层窗口。在抖音直播伴侣等软件中添加窗口采集，选择标题含“OBS 独立计时遮罩”的窗口，添加洋红色键（#FF00FF）以去除背景。关闭“直播伴侣窗口采集”可恢复游戏上的透明穿透遮罩。游戏启动前也可选取采集窗口。SDL 维护版各内容分别保存位置、字体与采集模式。

本地计时可离线使用。服务端的构建批准、历史云服务对新可执行文件的激活以及上传规则是独立操作。
