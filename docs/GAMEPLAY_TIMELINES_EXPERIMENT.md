# 自动玩法时间线实验

分支 `codex/gameplay-timelines`，内部版本 3.37.7.6，界面仍显示 3.37.7。“仙剑98 DX9 自动玩法（实验）”已作为 EXE 内置默认核心；没有有效历史选择时直接使用，不依赖随包 `LastCore`。玩家已有的有效手动核心选择仍保留。旧三种速度入口与其它游戏核心保留；没有新增硬核节点，也不修改游戏设置。

## 身份与本地记录

`GameplayModeReader` 每秒最多启动一个后台读取任务，读取目标 PAL 的 `Local\PAL98.GameplayMode.v1.<PID>`；PID、进程创建时间、seqlock、结构长度、版本和规则摘要必须一致。节点路径只取缓存，不读取配置文件或计算 SHA-256。身份来源及二进制布局见 PALDLL 的 `docs/GAMEPLAY_MODE_V1.md`。

`TimelineIdentity` 为 UTF-8、LF、末尾 LF 的以下文本之 SHA-256：

```text
PAL98.TimelineIdentity.v1
<rules_sha256>
<route_sha256>
<ordinary 或 hardcore>
```

基础内容、实际速度、随机技能规则/技能池、爱无限、村村通、已启用模块及抽卡有效卡集合参与规则。随机技能种子保存于跑次，不分线；配置名、设备绑定、工具路径、服务器和展示参数不分线。抽卡按集合排序，与抽取顺序无关。不能确认来源的内容保留为未归类，不能猜成原版。

前轮实测覆盖正式包六种内容及配套全局技能库的随机技能开关。本轮抽卡真实快照覆盖经典 v5 **1.0.21 / 1.0.22** 的 Profile 生成包：同时核对来源版本、保留的根资源身份和当前已生效描述符。对应 PalDrawCard 2.0.0-preview.12 仅扩展既有小野四卡到 1.0.22。实际快照已验证卡牌顺序、随机技能种子不分线，基础版本、卡牌集合、随机技能开关分别分线。旧无来源证据抽卡或未知基础包进入未归类。

正常目录为 `Timelines/<identity>/best.json`，接力文件在同目录；自动通关归档为时间戳 JSON。未识别、途中规则改变或硬核证据失效写入 `Timelines/Unclassified/`，不能覆盖普通最佳线。开局前异步装入对应参考，缺失时为零；开局后冻结，Reset 才重新分类。通关后正常关闭 PAL 不取消已完成资格；Jump 返回节点会恢复观察。

游戏标题融合实际速度、玩法及普通／硬核模式，以 `&` 分隔，不在底部重复显示；版本、比赛名称和异常提示继续保留。右键“当前玩法时间线…”显示完整摘要、规则及路径。“导入旧最佳线为当前玩法参考…”校验节点和顺序、保留源文件，写 `ReferenceTimeline=true/GameplayVerified=false`。旧文件不自动迁入。参考不能作为有效接力；同身份有效接力仍做既有时序/内容校验，且标记为导入来源，不重新当作本机完整新跑次上传。

## 比赛与硬核

当前联机入口使用 `PAL98.TimerOnline.v1`，外层认证为 `PAL98.TimerUploadAuth.v2`，接口统一为 `/api/v1/timer/`。日常配置编号使用独立的 `PAL98.RankingConfiguration.v1`，不改变本地 `TimelineIdentity`。旧成绩和签封保留原字节，不迁移或补签到新榜；不向旧服务器降级上传。认证、网络和存盘在后台，失败不阻塞本地计时。详见 [联机与排名](TIMER_ONLINE_3.37.7.6.md)。

日常新配置须由管理员命名公开；自定义比赛按明确登记的规则、内容、速度、路线判定资格，任意本地组合并不自动属于吴强比赛。硬核必须由规则 4 提供从开始到结束的连续证据；等待确认、途中开启、断连失效不能变成合格普通成绩。显示、OBS 样式及综合/硬核参考选择保留；日常硬核榜支持分页，自定义比赛硬核参考保留前三名次及并列。新节点无响应显示未知，请求绑定跑次、配置、路线、节点和榜单。

PALDLL、Helper、配置工具配套 1.6.8.15；读端保留已知旧版本兼容，缺少新排名事实时不猜测联机配置。实验 DLL 不进入正式 DLL 批准名单，标题显示“测试版”是预期。独立内嵌核验清单按实际 DLL 哈希匹配，包括 1.6.8.15，不复用旧构建代码预期值。计时器 EXE 冻结后必须生成配套独立认证 DLL，分别办理原云激活和联机上传批准；二者独立。

覆盖包保留原版 KeyChanger.exe。其硬核请求拦截本来就不依赖已知规则修订号，本轮用原二进制验证 1.6.8.14 / 规则 4 仍拒绝改键；无须破坏已有配置的程序哈希绑定。抽卡 EXE 的未锁定绑定由配置工具按精确已知新旧哈希事务迁移；锁定绑定由锁定者解锁更新，原签名不改。

## 自动验证与人工边界

`tests/run_gameplay_tests.ps1` 覆盖真实 native 帧解码、规则分线、参考/存盘/重开/接力隔离、通关后退出和 Jump；`tests/run_v165_timing_tests.ps1` 对照原三核心的节点、暂停、通关与主秒表；competition/hardcore 脚本覆盖新旧合同、旧服务器、回调与证据状态。

本机读取实际 PAL 生效快照验证三速度、六内容、随机技能不同种子和抽卡顺序；这不是完整路线游玩或实物键盘验收。尚需实物 USB/PS2、远程预配置确认、OBS 人工布局、完整通关及真实云/服务器、AMD、Win7、Windows ARM 验收。
