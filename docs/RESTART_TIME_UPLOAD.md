# 重启耗时上传与榜单计时口径

2026-10-13 配套更新保持 PalTimer 3.38.0.0、PalTimerOnline 1.0.0.4 和联机 API 1。
服务器更新继续基于 [PalServer PR #21](https://github.com/othercat/PalServer/pull/21)。计时器支持服务器先后更新两种顺序，旧服务器使用基础兼容格式。

## 能力协商和兼容连接

设备登记响应可选返回 `supported_features: ["restart-time.v1"]`，表示实时心跳及 Online.v2 成绩都支持可空的 `restart_ms`。缺省、null、空数组或仅有未知能力均按基础兼容处理；它不决定榜单是否计入重启时间。现有 `PAL98.TimerLive.v1`、`PAL98.TimerOnline.v2` 协议 ID 保持不变。

旧服务器的心跳完全省略 `restart_ms`，不发送 null 占位。成功 ACK 后标题为 `[不完全连接:ID]`，详情显示实际协议和未上传重启耗时；完整扩展的 ACK 后显示 `[已连接:ID]`。能力在设备登记时刷新，最多五分钟；后台重试也会刷新。升级、回滚保持同一实时会话和 ID，能力声明本身不会提前改变成功状态。鉴权失败、心跳过期仍按原规则断线。

通关时验证完整事实，保留原始 Run、Payload 和签封，同时由原生产构建生成仅省略根 `restart_ms` 的兼容签封。首次请求挑战前按能力原子保存选择；存储失败不发送，重试、重启及服务器升级均沿用已选择的原始字节。同一 run_id 不换内容重传；旧服务器收到的记录不含重启耗时，本地完整事实始终保留。

历史记录没有兼容签封时不补签、不改写：原 payload 本来没有该字段的继续上传，已含该字段的等待支持扩展的服务器。服务器仅支持 Online.v1 时，Online.v2 成绩仍保留待升级，不通过删除审核事实来降级；实时基础连接照常。队列读取上限为 1 MiB，以容纳两份有界签封。

服务端继续接收旧计时器的设备登记、Live.v1、Online.v1/v2；重启耗时缺省保持未知，已测零保持 0，原始成绩和签封不重写。

## 数据与兼容

PAL98、PAL98DX9、PAL98UNHAPPY 及继承 DX9 的自动玩法核心读取现有 ST 重启／空闲秒表，
以累计整数毫秒写入本地记录 `RestartMilliseconds`，保留旧 `Idle` 显示字段。
有效旧记录中的 `Idle` 可恢复已记录耗时；缺值、显式 null 或无效值保留未知，不能变成已测零。
显式未知但存在本地 `Idle` 的记录继续保留这部分观测，直到重置后建立新跑次。

宿主通过 `OnlineSnapshotV1.Extensions["restart_ms"]` 传给联机模块；未知时省略扩展。
模块在 Online.v2 成绩和 Live.v1 快照中发送可空 `restart_ms`：null 为未记录，0 为已记录且没有耗时。
单字段上限沿用 86,400,000 ms，超界完赛记录在本地拒绝；实时页面发出 invalid 状态，避免无效值反复破坏连接。
旧成绩格式保持原字段集。离线队列保留原签封字节，不能为了兼容旧服务器删除字段后重签。

通关绑定的观测冻结重启耗时，重复通关发布不改写该值；重置归零。
主计时和节点秒表仍独立。没有修改 F9、反作弊、保存／读档、云存读档、路线节点、
进程匹配、内存地址或读写接口；未在计时线程增加网络或磁盘访问。
标题和读档等待是否计入重启耗时沿用现有 ST 语义。

## 服务器显示

日常榜或自定义比赛开启“计入重启时间”后，服务器计算 `ranking_ms=total_ms+已记录 restart_ms`。
关闭时按原始 `total_ms` 排名。旧未知成绩继续参与排名，并显示“未记录重启时间”。
计时器的个人最佳、本次通关和硬核领先显示服务器返回的 `ranking_ms`，兼容旧响应回退到主计时。
节点与完整最佳线继续使用主计时，不受总榜重启开关影响。

DLL 的 1.7.2／1.7.2.1 字符串在玩家可见标题中显示为 1.72；原始记录、文件版本、
签名身份及版本比较保留完整版本。

PalCompetitionRegistration.public.json。交付目录同时提供现有公共依赖和 EXE 配置，
不包含用户设置、凭据、存档或私钥。

新增 DLL 的精确核验目录对应 SHA-256
`01d8b88fef06232b857be88aba9de6d8d00577d3496fb3032381de4a55a20afa`，
与同次 PAL.map 配对。它没有自动取得正式 DLL 批准；同版本号不会继承其他哈希的批准。
