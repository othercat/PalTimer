# 可扩展挑战规则传输

Refs othercat/sdlpal-lostedit#189、#115。先前的计时器传输迁移来自 PalTimer#52，本轮跨组件实现与验收统一记录于 SDLPal Issue #189。

主 EXE 保留 r85 的 3.38.4.11，SHA256 为 `ac332a3ffdb1f75922f5a2bb21f2afccce353d79488968ebc8d81bfc740687a3`。Online 升级至 1.0.0.25，使用原发布者配套构建 Auth 和公开登记；没有登记或批准生产身份。

正式 Online 项目不编译逐条规则 DTO、RuleKeys 或 INI 生成器。ChallengeRelayContract 验证身份、修订、审批、协议和资源边界，按有界 JSON 转发规则文档、目录及激活响应。目录扩展字段放在 catalog_metadata，格式版本及能力声明原样转发。未知字段不代表游戏已经执行该机制。

HTTP 单响应上限 1MiB，IPC 上限 8MiB；本地缓存限制为 6MiB，为激活响应留出空间。目录及报名列表分页读取，检查稳定快照和向前推进的偏移，支持旧服务不分页的显式适配。分页变化、容量超限或网络失败时保留原磁盘缓存和上一次可用响应。身份刷新倒计时单独保存，不覆盖挑战快照。

配套 PalServer 已实现 PAL.RulePackage.v2 上传、类型化网页编辑、不可变定义和值、规范化 SHA256 与 INI 编译；ConfigTool 1.7.2.43 独立校验、核对实际引擎能力、锁定 INI、保存及重开快照。旧 6/13/14 条合同通过显式 v1 适配读取。已有机制的新组合和受支持参数可通过数据上传更新，全新机制仍须更新引擎。r85 引擎支持已实现的 14 项能力，不能静默启用 r86 新机制或新修正版本。

同一套正式签名组件验证了 14/15/64/256 条规则、结构化参数、未知格式转发、分页变化及超限保留缓存。配置工具、签名计时器 CLI、真实本地 HTTP 服务和原生游戏联调另见 SDLPal Issue #189 报告。三套内核、计时、暂停、内存读取、路线和 OBS 沿用原主 EXE。

本轮组件和证据归 PALWork/artifacts/so-lostedit-issue-189/timer，完整游戏归 r86 发行目录。没有提交、推送、合并或部署生产服务。自动检查不代替 F9、路线、OBS、生产联网和玩家实机验收，Issue 保持开放。
