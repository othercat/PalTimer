# 高级买卖合同（Refs #51 / othercat/sdlpal-lostedit#187）

r84配套计时器3.38.4.11、在线模块1.0.0.23在规则列表末尾追加第14项`advanced_trade`，INI为`AdvancedTrade`及`PriorityAdvancedTrade`。规则默认关闭，优先级默认0；原13项位序保持。计时、暂停、分段、内存地址及PB逻辑没有调整。

在线快照、修订、报名、激活和本地恢复使用同一合同。接受旧6/13项目录和关闭新规则的旧INI；旧合同不得声称开启新规则，旧13项优先级保持。布尔字段严格校验，拒绝字符串或数值代替布尔。

配置工具的“玩法设置”可选择此规则，在线挑战由服务端目录提供。关联Pal98ConfigTool#72、PalServer#52。服务端尚未部署，新规则的生产联网验收仍待部署与真实审批；本地测试使用隔离loopback服务，不注册生产身份。
