## 测试确认的修正

首次运行记录保留在 `artifacts/v165-timing-20260914-084638-489`，当时 7 组通过、3 组失败。失败定位到两处行为：

1. `LoadGame` 在校验内容和分类之前清空 `LoadedSrpgRequiresGameRestart`。现改为仅在成功导入时更新；跨类或跨内容被拒绝时保留之前的待处理接力状态。
2. `GetGameVersion` 在游戏退出后丢失比赛名称。现随已核验的运行快照缓存比赛名称，未知的新运行时清空旧缓存，重置时清除；导出增加 `GameVersion` 和 `TournamentDisplayName`，结束后保留已确认的完整显示身份。

没有新增核心或时间线，没有删除梦幻、魂牵支持，没有修改固定内存、轮询周期、节点或反作弊判定。

## 证据边界

拒绝导入和接力的检查调用真实生产入口，并先证明纯校验将拒绝，避免测试意外落入 PAL.exe 自动连接路径。旧格式成功恢复测试使用仅在测试宿主定义的派生类跳过可选连接探测，随后检查真实恢复代码写入的未验证状态；实际三个核心的归属校验另行使用生产策略验证。这不等同于带真实进程的成功接力往返。

遮罩检查调用生产绘制代码到位图，验证窗口未显示且未创建窗口句柄。简繁分别覆盖 `zh-CN`、`zh-TW`，以及宋体、細明體的离屏布局。位图证据不证明 OBS 枚举、透明通道、显示器 DPI 或实际直播捕获。

仍需人工或配套运行验收：真实 PAL.exe 三类正式/四种非速通跑线、实际进程重启和热切换、节点与 F9/香蕉反作弊、带资源/附属存档的成功接力、云服务器往返、比赛锁真实读取，以及 OBS 窗口捕获和结束画面的实际显示。未在本次测试中关闭他人进程或修改完整包。
